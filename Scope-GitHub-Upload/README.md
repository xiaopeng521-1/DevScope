# DevScope

轻量级 Windows 应用与开发环境管理工具，使用 C++17 和原生 Win32 UI，不依赖浏览器运行时。

## 使用

下载仓库中的 **DevScope.exe**，在 Windows x64 上运行。双击“一键创建桌面快捷方式.cmd”可创建桌面入口，需要同时保留 `Create-DesktopShortcut.ps1`。管理员操作会请求 Windows UAC 授权。

## 功能

- 扫描本地磁盘、安装登记和开发环境；扫描过程中逐步展示结果。
- 按应用归并辅助程序，显示应用图标、安装位置、缓存位置、权限、磁盘与内存占用；Java/JDK 等环境分组展示。
- 检查目录内的程序及可获取的使用记录；无法确认的历史使用信息显示未知。
- 应用卸载、文件/文件夹强制删除，以及确认范围后的整目录清理。
- 删除流程只需一次范围确认：优先登记的静默卸载命令，其次软件自带卸载器，再清理残留。
- 对确认范围内的服务、进程、Run/RunOnce 自启项进行处理；必要时尝试修复文件权限。
- 占用文件可安排重启删除，结果显示在详情区；待重启不等同于已删除。
- 迁移位置、路径引用检查，以及扫描等待时的 2048、贪吃蛇、记忆翻牌小游戏。

## 删除能力与限制

删除不会进入回收站。请核对确认窗口中的完整路径，范围内可能包含个人配置和文件。结束进程可能导致未保存内容丢失。

权限修复仅针对确认范围：保存原所有者和 DACL，必要时关闭继承并重新授予权限；未删除时尝试恢复。系统根目录、工具自身目录及不安全路径仍受保护。不会通过链接递归删除目标，也不会修改多硬链接文件的权限。

软件自带卸载器没有静默模式时，仍可能显示自己的窗口。进程、服务、驱动自保护可能阻止清理；未知关联数据、计划任务和历史系统设置不保证全部清除。本工具不承诺“零残留”或不可恢复的数据销毁。

重启删除只代表请求已提交。重启前不要在排队路径重新安装软件或保存新文件，重启后请重新扫描核实。

## 构建

需要 Windows、支持 C++17 的 MinGW-w64，以及 Windows 资源编译器 `windres`。

```powershell
windres app.rc -O coff -o app.res.o
g++ main.cpp app.res.o -o DevScope.exe -std=c++17 -O2 -municode -mwindows -static -s -lcomctl32 -lshell32 -ladvapi32 -lpsapi -lgdi32 -lole32 -lversion -lwevtapi -luuid
```

也可使用 CMake：

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build --config Release
```

## 验证

`*_tests.cpp` 为独立测试程序。部分测试创建隔离文件、临时注册表测试键或测试子进程；请在测试环境运行。已覆盖路径归属、异步详情、卸载等待、权限修复和恢复、文件占用、清理结果反馈及重启计划顺序。重启队列测试使用模拟接口，不代表所有第三方软件都已验证。
