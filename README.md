DevScope 是一款轻量级 Windows 桌面工具，用于查看电脑上的应用、开发环境、安装位置和已识别的缓存目录。它将扫描、目录检查、卸载和文件清理集中在一个界面中，扫描结果逐步显示，无需等待全部扫描结束。

## 快速开始

1. 下载仓库中的 [DevScope.exe](DevScope.exe)，在 Windows x64 上运行。
2. 点击 **重新扫描**，等待应用图标逐步出现。
3. 点击应用，查看安装位置、关联目录、权限和资源占用。
4. 根据需要选择 **检查目录**、**迁移位置** 或 **永久删除**。

程序使用原生 C++，无需安装浏览器运行时。需要提升权限的操作会触发 Windows UAC 授权。

如需桌面快捷方式，请将 `DevScope.exe`、`Create-DesktopShortcut.ps1` 和 `一键创建桌面快捷方式.cmd` 放在同一目录，双击 `.cmd` 文件。

## 主要功能

### 应用与开发环境扫描

- 扫描本地固定盘和移动盘，结合安装登记、路径和可执行文件信息识别应用。
- 逐步展示扫描结果，使用应用自身图标；能确认归属的辅助程序合并到所属应用。
- 显示安装位置、已识别缓存目录、访问权限及可获取的磁盘和内存占用。
- Java/JDK、Python、Node.js、C/C++、.NET 等开发环境分组展示。
- 系统组件集中展示；归属不明确的项目单独列为待识别程序。
- 支持搜索、占用排序和目录大小统计。

### 目录检查与位置管理

- 检查目录内包含的主程序和辅助组件。
- 显示正在运行的进程及可获取的启动记录；无法确认的使用历史显示为未知。
- 提供位置迁移、限定范围内的路径引用检查，以及环境变量相关提醒。

迁移并不等于完整重装。复杂应用的服务、注册表或其他位置引用可能需要额外处理。

### 卸载和文件清理

- 优先使用软件登记的静默卸载命令，其次使用软件自带卸载程序。
- 支持单个文件、文件夹，以及明确确认范围后的共用目录整体清理。
- 检查路径匹配的服务、进程和 Run/RunOnce 自启项。
- 对权限不足的目标尝试修复所有权和访问权限，再执行删除。
- 为可延后处理的占用文件和残留目录安排重启删除。
- 本工具的删除操作合并为一次范围确认，结果显示在详情区。

### 扫描时的小休息

内置 **2048、贪吃蛇、记忆翻牌** 三款小游戏。扫描超过 30 秒时可选择打开，游戏不会中断后台扫描。

## 卸载与清理

一次确认后，程序按目标情况执行以下流程：

1. **优先卸载**：使用已登记的静默命令或软件自带卸载器；没有可用卸载器时直接清理。
2. **处理关联项**：核对相应服务、自启项和进程，必要时尝试修复文件权限。
3. **清理残留**：删除确认范围内的文件，并处理清理后为空的直接父目录。
4. **安排重启删除**：为可排队的残留提交请求，显示待重启状态；不会自动重启电脑。

**部分残留需重启后才会消失；未能安排删除的项目会提示。** 重启前不要向排队路径保存新文件或重新安装软件，重启后请重新扫描核实。

卸载器明确返回失败或取消状态时，程序停止后续清理。没有静默模式的第三方卸载器仍可能显示自己的窗口，Windows UAC 授权也不能省略。

## 使用边界

> 删除不进入回收站。请仔细核对路径并先保存工作，范围内可能包含个人文件、配置和缓存。

- 管理员权限不等于能绕过所有保护；文件占用、受保护服务和内核驱动仍可能阻止删除。
- 权限修复仅针对确认范围内的目标，不修改父目录权限。未删除时尝试恢复原权限，恢复失败会记录。
- 系统根目录、本工具所在目录和不安全路径受到保护，不会通过链接递归删除其他位置，也不修改多硬链接文件的权限。
- 扫描和关联识别不保证完全覆盖。未知缓存、计划任务、其他用户数据和历史系统设置不保证全部处理。
- “已安排重启删除”不代表已经删除；请以重启后的检查结果为准。
- 本工具不承诺零残留，也不提供不可恢复的数据粉碎保证。

建议先在虚拟机中验证重要软件的卸载和迁移行为。

## 源码编译

### 环境要求

- Windows x64。
- 支持 C++17 的 MinGW-w64 工具链。
- `g++` 和资源编译器 `windres` 已加入 PATH。
- 使用 CMake 构建时，需要 CMake 3.16 或更新版本。

### 直接编译

在项目根目录执行：

```powershell
windres app.rc -O coff -o app.res.o
g++ main.cpp app.res.o -o DevScope.exe -std=c++17 -O2 -municode -mwindows -static -s -lcomctl32 -lshell32 -ladvapi32 -lpsapi -lgdi32 -lole32 -lversion -lwevtapi -luuid
```

### 使用 CMake

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

编译前请关闭正在运行的目标程序，避免输出文件被占用。
